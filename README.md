# Stubby & Co: code from the episodes

Companion code for the **Stubby & Co** YouTube channel, which explains what actually happens inside
your software, one small disaster at a time.

| episode | folder | what's inside |
|---|---|---|
| 1. Your AI model is 20× slower on phones. Here's why. | [`ep01-onnx-partitions`](ep01-onnx-partitions) | a script that counts how ONNX Runtime split your model across CPU, XNNPACK, NNAPI and Core ML |
